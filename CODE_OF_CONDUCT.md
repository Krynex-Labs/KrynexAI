# Code of conduct

## Our standard

Be decent. Assume good intent, give useful feedback and keep discussions about the
code rather than the person.

## Unacceptable behaviour

Harassment, insults, personal attacks and deliberate disruption are not welcome here.
Maintainers may edit or remove comments and commits that cross that line.

## Scope

This applies to issues, pull requests and any other project space. Report problems
privately to krynexlabs@gmail.com.
