# Security policy

This is a static site with no backend and no server-side storage. Theme settings,
site tasks, coins and the time record live in the browser's `localStorage`.

## Reporting a vulnerability

Please report security issues privately to **krynexlabs@gmail.com** with a description,
steps to reproduce and, if possible, a suggested fix. Do not open a public issue for
an unpatched vulnerability.

## Supported versions

Only the latest commit on the default branch is supported.
